📖 What is IFSC?

Understanding IFSC Code

IFSC (Indian Financial System Code) is an 11-character alphanumeric code assigned by the Reserve Bank of India to every bank branch. It uniquely identifies each branch participating in electronic payment systems.

IFSC codes are essential for:

  • NEFT — National Electronic Funds Transfer
  • RTGS — Real Time Gross Settlement
  • IMPS — Immediate Payment Service
  • UPI — Unified Payments Interface
  • Online banking and mobile transfers
🔍 IFSC Format

How to Read IFSC Code

  • First 4 characters — Bank code (e.g. SBIN = State Bank of India)
  • 5th character — Always 0 (reserved for future use)
  • Last 6 characters — Branch code (unique for each branch)

Example: SBIN0000628

SBIN = State Bank of India, 0 = reserved, 000628 = specific branch code.
