# Find My Pin Code 📍

A modern, SEO-optimized landing page to help users find the **pin code of their location on a map**.

## Features

- 🗺️ Interactive map-based pin code finder
- 📍 GPS location detection
- 🌐 Supports 200+ countries (PIN codes, ZIP codes, postcodes)
- 📱 Fully mobile-responsive design
- ⚡ Fast, free & no signup required
- 🔍 SEO optimized with structured data (JSON-LD)

## Live Demo

Deploy via GitHub Pages or any static hosting.

## Tech Stack

- HTML5
- CSS3 (Vanilla, glassmorphism design)
- Vanilla JavaScript
- No external dependencies

## Getting Started

1. Clone the repo
2. Open `index.html` in your browser
3. Deploy to GitHub Pages or any static host
